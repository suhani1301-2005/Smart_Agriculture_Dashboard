# 🌾 Smart Agriculture Business & Crop Profitability Intelligence

## 📌 Project Overview
An interactive Power BI dashboard designed to analyse agricultural production and mandi market prices. The project transforms raw agricultural data into meaningful business insights to support better agricultural planning and decision-making.

## 🛠️ Technologies Used
- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV
- Data Cleaning and Visualization

## 📊 Key Dashboard Features
- KPI cards for agricultural performance monitoring.
- Crop production trend analysis.
- State-wise and district-wise agricultural analysis.
- Seasonal crop production analysis.
- Top 5 commodity mandi price comparison.
- Business insights for agricultural decision-making.

## 📁 Datasets
1. Crop Production Dataset
2. Mandi Price Dataset

Both datasets were used for agricultural production and market price analysis.

## 📈 Analytics
- Descriptive Analytics
- Diagnostic Analytics
- Predictive Analytics
- Prescriptive Analytics

## 🚀 How to Run
1. Download the `.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded Power BI file.
4. If prompted, update the dataset file paths.
5. Explore the interactive dashboard.

## 🎯 Project Objective
To analyse agricultural production patterns and market prices using data visualization and business intelligence techniques.
